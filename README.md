# OUTSTATE

Storefront for OUTSTATE, Portuguese streetwear. It's a static site: open `index.html` in a browser, or serve the folder with `python3 -m http.server`.

- `index.html`: page structure (hero, manifesto, shop, lookbook, story, newsletter, footer, bag drawer)
- `styles.css`: design tokens and styles
- `script.js`: product data, filters, bag (saved in localStorage), scroll reveals

The campaign and product images were generated with Higgsfield and load from its CDN (URLs in `script.js`).
